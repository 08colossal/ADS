Exercícios GRAFOS

1.
a.	Não direcionado
b.	V = {A, B, C, D, E}
c.	A = {{A,B}, {B,A}, {B,C}, {C,B}, {A,C}, {C,A}, {C,D}, {D,C}, {D,E}, {E,D}, {E,C}}
d.	Graus: A = 2 ; B = 2; C = 4; D = 2; E = 2;
e.	A, D, E e B -> Adjacentes de C
f.	Matriz de adjacência em ordem alfabética:
		A B C D E
	A	0 1 1 0 0
	B	1 0 1 0 0
	C	1 1 0 1 1
	D	0 0 1 0 1
	E	0 0 1 1 0

g.	Lista de adjacências:
	A -> B -> C
	B -> A -> C 
	C -> D -> E -> B -> A
	D -> E -> C
	E -> C -> D

h.	B e E -> {B, C, E}
i.	Tem ciclo: pode se dizer que sim, não é direcionado então não tem um início específico, 	mas todos os vértices estão conectados por 'C'.
	Exemplo: A -> B -> C -> D -> E -> C -> A
j.	É conexo: Sim! Você pode passar por todos os vértices usando 'C'.

d.	A = 2; B = 3; C = 1; D = 2; E = 2;

f.	Matriz de Adjacência:
		A B C D E
	A	0 1 0 1 0
	B	1 0 1 0 1
	C	0 1 0 0 0
	D	1 0 0 0 1
	E	0 1 0 1 0

g.	Lista de adjacência:
	A -> B -> D
	B -> A -> E -> C
	C -> B
	D -> A -> E
	E -> D -> B

h.	C -> B -> E -> D
i.	Sim, B -> E -> D -> A -> B
j.	Sim, 4 vértices (a, b, d, e) estão conectados e podem ser acessados uns pelos outros.

5.

	1	1 1 0 0 1 0
	2	1 0 1 0 1 0
	3	0 1 0 1 0 0
	4	0 0 1 0 1 1
	5	1 1 0 1 0 0
	6	0 0 0 1 0 0

	1 -> 1 -> 2 -> 5
	2 -> 1 -> 5 -> 3
	3 -> 2 -> 4
	4 -> 3 -> 5 -> 6
	5 -> 1 -> 2 -> 4
	6 -> 4
