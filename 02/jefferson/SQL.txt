Criado nos anos 70 para padronizar;

DDL - data definition language : estrutura, esquema do db | CREATE | ALTER | DROP (apagar -> a estrutura inteira não o dado)
DML - data manipulation language :  | INSERT | UPDATE | DELETE
DQL - data query language : consulta | SELECT 
DCL - data control language : sintaxe de permissão | GRANT | REVOKE
DTL - data trasaction language : transição, | BEGIN | COMMIT | ROLLBACK

DOMÍNIOS
:

INTEGER           4 bytes
BIGINT            8 bytes
SMALLINT          2 bytes
NUMERIC/decimal   variável (você define as casas decimais)
REAL              4 bytes (salva a conta ex 1.8 * 10^-38)
DOUBLE PRECISION  8 bytes (salva a conta ex 1.8 * 10^-308)


ex:
CREATE TABLE Numeros{

small_int_col SMALL INT,
integer_col INTEGER,
numeric_col NUMERIC(10, 2),

}




Tipos de dados_texto :

ex:
